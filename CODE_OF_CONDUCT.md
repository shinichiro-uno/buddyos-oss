# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, as its code of conduct:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

All contributors and maintainers are expected to follow it in every project space (issues, pull requests, discussions, and any chat linked from this repository).

## Reporting

Report unacceptable behavior privately to the maintainers at buddyos@protoductai.com.

All reports are reviewed and investigated promptly and fairly, and the reporter's privacy is respected. Enforcement follows the "Enforcement Guidelines" section of the Contributor Covenant 2.1.
